# Minecraft Distance Calculator 📏🗺️

A lightweight Python script to calculate the exact straight-line distance (Euclidean distance) between two sets of coordinates in Minecraft.

## What is it for?
Whether you want to measure the distance from your base to a faraway village, a woodland mansion, or a nether portal, this tool uses the Pythagorean theorem to instantly calculate how many blocks apart they are.

## Requirements
- Python 3.x installed.

## How to use it

1. Clone this repository or download the `minecraft_distance.py` file.
2. Open your terminal or command prompt in the folder containing the file and run:

```bash
python minecraft_distance.py
